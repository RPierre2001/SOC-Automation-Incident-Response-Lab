# Wazuh SIEM Deployment and Configuration

## Overview

This phase involved deploying Wazuh SIEM on an Ubuntu 24.04 LTS cloud server hosted through Vultr.

The objective was to establish a centralized security monitoring platform capable of receiving endpoint telemetry, generating security alerts, and supporting automated incident response workflows.

## Technologies Used

- Wazuh SIEM
- Ubuntu 24.04 LTS
- Vultr Cloud Infrastructure
- SSH
- Linux Command Line
- Windows 10
- Sysmon

## Step 1: Cloud Server Provisioning

Provisioned an Ubuntu 24.04 LTS (64-bit) cloud instance using Vultr.

The server was designated to host the Wazuh security monitoring environment.

After provisioning the instance, I connected to the server remotely using SSH to perform system administration and configuration.

## Step 2: Wazuh Installation

Installed and configured Wazuh on the Ubuntu cloud server.

Wazuh served as the centralized security monitoring platform for collecting and analyzing security events generated by the Windows 10 endpoint.

The environment was configured to support security event monitoring and alert generation.

## Step 3: Windows Endpoint Monitoring

Integrated the Windows 10 virtual machine with the Wazuh monitoring environment.

The Windows endpoint was configured with Sysmon to generate detailed security telemetry.

Wazuh was used to monitor endpoint activity and identify security events relevant to the lab's detection scenarios.

## Step 4: Verify Wazuh Manager Operation

Verified the status of the Wazuh manager using the Linux command line.

Example command:

```bash
sudo systemctl status wazuh-manager
```

The service status was checked to confirm that the Wazuh manager was operating.

## Step 5: Review Security Alerts

Reviewed security alerts generated by Wazuh.

The following command can be used to inspect the alerts log:

```bash
sudo tail -f /var/ossec/logs/alerts/alerts.json
```

This provides visibility into security alerts processed by the Wazuh manager.

## Step 6: Security Detection Testing

Conducted controlled testing using Mimikatz within the Windows 10 virtual machine.

Observed corresponding Sysmon activity and Wazuh security alerts.

The alerts were used to validate endpoint monitoring and support the subsequent Shuffle SOAR automation workflow.

## Results

- Deployed Wazuh on an Ubuntu 24.04 LTS cloud instance.
- Established a centralized security monitoring environment.
- Monitored security activity originating from the Windows 10 virtual machine.
- Observed Wazuh alerts associated with controlled security testing.
- Prepared the environment for integration with Shuffle SOAR.
